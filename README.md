# Nessim Web Creations

Crée un site web professionnel pour un développeur freelance qui s'appelle Nessim, spécialisé dans la création de sites internet pour particuliers et entreprises.

Objectif du site : Présenter mes services de création de sites web et permettre aux visiteurs de me contacter via un formulaire qui envoie un email avec leur demande.

Structure du site (one-page avec sections) :

Header / Navigation

Logo "Nessim" ou "Nessim Dev"

Menu : Accueil, Services, Portfolio, À propos, Contact

Bouton CTA "Demander un devis" bien visible

Section Hero

Titre accrocheur du type "Je crée le site web dont votre entreprise a besoin"

Sous-titre expliquant que je conçois des sites modernes, rapides et sur-mesure

Bouton principal vers le formulaire de contact

Design moderne, épuré, avec une belle typographie

Section Services

Cartes présentant les services : Site vitrine, Site e-commerce, Landing page, Refonte de site existant, Maintenance

Icônes pour chaque service

Courte description pour chacun

Section Pourquoi me choisir / Avantages

Design moderne et responsive

Délais rapides

Prix transparents

Accompagnement personnalisé

Utiliser des icônes et un layout en grille

Section Portfolio / Réalisations

Grille de 3 à 6 projets fictifs/exemples avec image, titre et courte description

Effet hover élégant

Section À propos

Présentation de Nessim : développeur passionné, expérience, approche de travail

Photo (placeholder)

Section Contact / Formulaire (la plus importante)

Formulaire avec les champs suivants :

Nom complet (obligatoire)

Email (obligatoire)

Téléphone (optionnel)

Type de projet (menu déroulant : Site vitrine, E-commerce, Landing page, Autre)

Budget approximatif (menu déroulant ou champ libre)

Message décrivant le projet (zone de texte, obligatoire)

Bouton "Envoyer ma demande"

Le formulaire doit envoyer un email de notification à mon adresse avec le contenu du formulaire (utiliser une intégration d'envoi d'email, par exemple via Resend ou un service compatible avec Lovable/Supabase)

Message de confirmation après envoi ("Merci, je reviens vers vous sous 24h")

Footer

Coordonnées (email, réseaux sociaux)

Copyright

Liens rapides vers les sections

Style visuel :

Design moderne, professionnel et épuré

Palette de couleurs sobre (par exemple bleu foncé / blanc / accent orange ou vert)

Typographie moderne (type Inter, Poppins)

Site entièrement responsive (mobile, tablette, desktop)

Animations légères au scroll pour dynamiser le rendu

Technique :

Formulaire fonctionnel connecté à Supabase pour stocker les demandes et déclencher l'envoi d'un email de notification

Validation des champs obligatoires

Site rapide et optimisé SEO (titres, meta description)
